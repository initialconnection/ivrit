# Ivrit Word Game

A Hebrew learning game written entirely in English letters (transliteration), for learners who can't read Hebrew script yet.

## What it does
- Flashcards by topic: everyday basics, people & family, food & home, numbers 1–10
- Practise either way: Hebrew → English or English → Hebrew
- Words you miss come back a few cards later until you've learned them all
- Remembers your chosen topics and how many rounds you've finished (in your browser)

## Project layout
- `index.html` – the page
- `css/style.css` – colors, fonts and layout
- `js/words.js` – all the word lists (edit this to add words or topics)
- `js/app.js` – the game logic

## Running it
Open `index.html` in a browser. No installs or build step needed.
It's published free with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).
